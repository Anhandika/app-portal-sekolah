01 — OVERVIEW
Tentang Aplikasi
PAS (Portal Academy Sekolah) adalah platform akademik digital multi-sekolah yang dirancang untuk melayani beberapa sekolah secara simultan. Menghubungkan siswa, guru, dan administrator dalam satu ekosistem terpadu.

Multi-School Architecture

Super Admin mengelola beberapa sekolah, masing-masing memiliki Admin Sekolah sendiri. Fitur dapat diaktifkan/nonaktifkan per sekolah.

📱

Web + Android (APK)

Tersedia sebagai aplikasi web responsif dan Android native via Capacitor, mendukung biometrik dan push notification.

⚡

Real-time Communication

Chat dan notifikasi real-time via Laravel Reverb WebSocket dengan fallback polling 15 detik.

🧠

AI-Powered Moderation

Moderasi konten menggunakan Google Gemini 2.0 Flash Vision untuk analisis keamanan gambar.

DESIGN PATTERNS

🏛 MVC Architecture

Standard Laravel MVC dengan 27 controller, 33 model, Blade views, dan Service layer.

🔄 Dual Interface

Data sama dilayani via web (session) dan API (Sanctum token) untuk mobile & web.

🟢 RBAC Middleware

Role-Based Access: Super Admin, Admin Sekolah, Guru, Siswa.

🌐 Multi-Tenancy

Architecture multi-sekolah dengan school_id FK dan feature toggle per sekolah.
