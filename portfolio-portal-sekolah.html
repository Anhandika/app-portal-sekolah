01 — OVERVIEW
Tentang Aplikasi
Portal Sekolah adalah platform akademik digital multi-sekolah yang dirancang untuk melayani beberapa sekolah secara simultan. Menghubungkan siswa, guru, dan administrator dalam satu ekosistem terpadu.

Multi-School Architecture

Super Admin mengelola beberapa sekolah, masing-masing memiliki Admin Sekolah sendiri. Setiap sekolah dapat mengaktifkan/menonaktifkan fitur secara independen.

📱

Web + Android (APK)

Tersedia sebagai aplikasi web responsif dan aplikasi Android native via Capacitor, mendukung autentikasi biometrik (fingerprint) dan push notification.

⚡

Real-time Communication

Sistem chat dan notifikasi real-time via Laravel Reverb (WebSocket) dengan fallback polling. Mendukung chat kelompok, kelas, eskul, dan pesan pribadi.

🧠

AI-Powered Moderation

Moderasi konten berbasis AI menggunakan Google Gemini 2.0 Flash Vision untuk analisis keamanan gambar, dipadukan dengan filter kata kunci dan pelaporan komunitas.

DESIGN PATTERNS

🏛 MVC Architecture

Standard Laravel MVC dengan 27 controller, 33 model, dan Blade views. Service layer untuk FCM, Firebase Storage, dan Image Safety.

🔄 Dual Interface

Data yang sama dilayani via web routes (session auth) dan API routes (Sanctum token auth) untuk mobile dan web.

🟢 RBAC Middleware

Role-Based Access Control dengan role middleware kustom. Super Admin, Admin Sekolah, Guru, dan Siswa.

🌐 Multi-Tenancy

Architecture multi-sekolah dengan school_id sebagai foreign key. Feature toggle per sekolah via SchoolFeature model.
