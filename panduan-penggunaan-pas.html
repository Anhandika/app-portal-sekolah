Langkah 1 — Membuka Aplikasi

Buka PAS lewat Web atau Install APK

PAS bisa dibuka langsung di browser HP/laptop, atau di-install sebagai aplikasi Android agar bisa memakai sidik jari dan notifikasi.

1

Lewat browser

Ketik alamat portal sekolah Anda di Chrome (contoh: nama-sekolah.up.railway.app). Anda langsung melihat halaman depan PAS.

2

Install aplikasi Android

Di halaman depan, ketuk Unduh Aplikasi Android. Buka file APK → ketuk Install → izinkan bila diminta. Ikon PAS muncul di beranda HP.

3

Beri izin yang diminta

Saat pertama dibuka, izinkan Notifikasi, Lokasi, dan Kamera. Izin ini dipakai untuk pengumuman, absensi GPS, dan verifikasi wajah.

Tips: selalu unduh APK hanya dari situs resmi sekolah. Jangan dari grup chat tak dikenal — berisiko aplikasi palsu pencuri akun.

Langkah 2 — Mendaftar Akun Baru

Daftar Pakai Kode Sekolah

Pendaftaran dikunci dengan kode resmi agar hanya warga sekolah yang bisa masuk.

1

Minta kode ke admin sekolah

Kode terdiri dari ID sekolah + kode wilayah (contoh 1851372). Tanyakan ke wali kelas atau TU.

2

Ketuk "Daftar" lalu masukkan kode

Masukkan kode → ketuk Cek. Bila valid, nama sekolah tampil otomatis.

3

Pilih peran & isi data diri

Pilih Siswa atau Guru, isi nama, NIS/NIK, email aktif, dan kata sandi. Unggah foto profil yang jelas.

4

Tunggu verifikasi admin

Akun berstatus Menunggu. Admin sekolah memeriksa data, biasanya < 1×24 jam. Anda akan bisa masuk setelah disetujui.

Kode salah/tutup? Pesan merah berarti kode keliru atau pendaftaran peran itu sedang ditutup — konfirmasi ke admin, jangan mendaftar berulang-ulang.

Langkah 3 — Masuk (Login)

Masuk ke Akun Anda

Gunakan email dan kata sandi yang didaftarkan. Centang "Tetap masuk" di HP pribadi agar tidak perlu login ulang.

1

Ketuk "Masuk Portal"

Dari halaman depan atau layar sambutan aplikasi.

2

Isi email & kata sandi

Ketuk ikon mata untuk mengintip sandi sebelum masuk.

3

Ketuk "Masuk ke Portal"

Tunggu animasi "Menghubungkan..." — Anda mendarat di Beranda.

Lupa sandi? Ketuk Lupa Password? → masukkan email → buka link reset dari inbox (cek spam bila tak ada). Lupa email? pakai menu Lupa Email? dengan NIK + nama.

Langkah 4 — Kunci PIN & Sidik Jari

Amankan Aplikasi Anda

Aktifkan kunci layar agar orang lain tak bisa membuka aplikasi meski HP dipinjam.

1

Buka Profil → Keamanan

Ketuk ikon orang di navigasi bawah → menu Keamanan.

2

Buat PIN 4–6 digit

Masukkan dua kali untuk konfirmasi. Hafalkan — jangan pakai tanggal lahir.

3

Aktifkan sidik jari (opsional)

Bila HP mendukung, aktifkan Biometrik agar buka kunci sekali sentuh.

Salah PIN 5× → aplikasi terkunci 30 detik. Tetap salah? Hubungi admin untuk reset — jangan hapus-install aplikasi (data lokal hilang).

Langkah 5 — Tour Beranda

Kenali Layar Utama

Beranda adalah pusat kendali: sapaan, statistik, menu fitur, dan navigasi bawah selalu dalam jangkauan jempol.

1

Kartu sapaan

Foto, nama, kelas, dan lonceng notifikasi (angka merah = belum dibaca).

2

Kartu statistik

Ringkasan Tugas aktif, % kehadiran, dan jumlah teman sekelas (ketuk untuk daftar).

3

Menu Utama 8 ikon

Absensi, Tugas, SPP, Chat, Perpus, Jadwal, Nilai, Eskul — ketuk untuk masuk.

4

Navigasi bawah

Beranda • Global • Absen • Chat • Tugas • Profil. Ikon biru = halaman aktif.

5

Tarik ke bawah = muat ulang

Di layar paling atas, tarik layar ke bawah lalu lepaskan untuk refresh data.

Langkah 6 — Absensi Harian

Absen Tiap Pagi

Absensi memakai GPS + verifikasi wajah agar tercatat valid di sekolah.

1

Buka menu Absensi

Dari Beranda atau tab Absen bawah. Pastikan GPS aktif & di area sekolah.

2

Ketuk "Absen Masuk"

Kamera terbuka dengan bingkai wajah — posisikan wajah di tengah, cahaya cukup, lepas masker.

3

Tunggu status "Berhasil"

Kartu berubah hijau + jam tercatat. Ulangi sore hari untuk Absen Pulang.

Gagal lokasi? Nyalakan GPS akurasi tinggi, buka Maps sebentar, lalu coba lagi. Gagal wajah? Cari tempat terang dan latar polos.

Langkah 12 — Chat

Kirim Pesan & Ikut Grup

Chat kelas otomatis tersedia; chat pribadi dan grup bebas bisa dibuat sendiri.

1

Buka tab Chat

Grup kelas sudah ada (hijau). Grup eskul (ungu), grup bebas (indigo), chat pribadi (foto).

2

Kirim pesan

Masuk utas → ketik → kirim. Titik hijau = sedang online. Pesan terkirim instan (real-time).

3

Buat grup / chat pribadi

Ketuk + → pilih anggota → beri nama grup. Untuk pribadi: dari daftar teman sekelas → ikon chat.

Etika chat: dilarang bullying, spam, dan konten SARA — pelanggaran berakibat pembatasan akun (lihat Kebijakan Global Portal).

Langkah 15–16 — Profil, Notifikasi & Keluar

Kelola Akun & Akhiri Sesi

Semua pengaturan pribadi terpusat di menu Profil (ikon orang, kanan bawah).

1

Edit profil & foto

Profil → Edit: perbarui nomor HP, foto (atur posisi dengan geser), lalu simpan.

2

Atur notifikasi

Profil → Notifikasi: pilih kategori (pengumuman/chat/tugas), cek status push FCM, minta pengecualian hemat baterai bila saran muncul.

3

Baca Pusat Bantuan & Tentang

Menu Bantuan/FAQ menjawab 32 pertanyaan umum + kebijakan; Tentang menampilkan versi aplikasi.

4

Keluar dengan tombol KELUAR

Gulir Profil paling bawah → KELUAR merah. Sesi, token, dan cache dibersihkan — aman di HP bersama.

Jangan keluar dengan menghapus data aplikasi / tombol recent-apps saja — sesi bisa menggantung. Selalu pakai tombol KELUAR.

Langkah 17 — Khusus Guru

Memberi Tugas & Nilai

Akun guru membuka tombol-tombol khusus yang tak terlihat di akun siswa.

1

Buat tugas baru

Menu Tugas → + Buat: pilih mapel & kelas, tulis instruksi, lampirkan file contoh, tentukan tenggat → Terbitkan. Siswa langsung dapat notifikasi.

2

Periksa pengumpulan

Buka tugas → daftar pengumpul vs belum. Ketuk nama siswa untuk melihat jawaban & lampirannya.

3

Beri nilai + umpan balik

Isi angka + komentar → Simpan. Nilai terkirim ke siswa seketika beserta notifikasi.

4

Kelola materi (LMS)

Menu mapel → + Materi: judul, isi/ringkasan, lampirkan PDF/video/link → Terbitkan per kelas.

5

Rekap & unduh

Gunakan Export PDF/Excel di daftar nilai dan pengumpulan untuk arsip & rapor.

Etika menilai: nilai yang sudah final sebaiknya tidak diubah diam-diam — sampaikan dulu ke siswa bila ada koreksi.

Langkah 18 — Khusus Admin Sekolah

Mengelola Sekolah

Panel admin dibuka dari browser laptop/komputer (tidak tersedia di aplikasi HP).

1

Masuk sebagai admin

Login dengan akun admin di browser → otomatis diarahkan ke Dashboard Admin berisi grafik siswa, kehadiran, dan keuangan.

2

Verifikasi pendaftar baru

Menu Akun Pengguna: periksa data pendaftar → Setujui (aktif) atau Tolak. Bagikan kode pendaftaran ke wali kelas.

3

Kelola data induk

Menu Sekolah: kelas, jurusan, mapel, jadwal pelajaran, data eskul & katalog perpus.

4

Catat SPP & unduh rekap

Menu SPP: input pembayaran per siswa; unduh rekap keuangan PDF/Excel tiap bulan.

5

Awasi konten & riwayat

Menu Global Portal: tinjau laporan konten; menu Riwayat: audit aktivitas pengguna mencurigakan.

Admin Pusat (pengelola multi-sekolah) memiliki menu tambahan: kelola daftar sekolah, admin sekolah, dan sakelar 12 modul fitur per sekolah.

Langkah 19 — Bantuan & Masalah

Butuh Bantuan?

Urutkan langkah ini sebelum panik — 90% kendala selesai di tiga baris pertama.

1

Cek koneksi & muat ulang

Pastikan online, lalu tarik-layar-untuk-refresh atau ketuk Coba Lagi.

2

Buka Pusat Bantuan / FAQ

Profil → Bantuan: 32 jawaban + kebijakan (atau dari halaman depan tanpa login).

3

Hapus cache aplikasi

Pengaturan HP → Aplikasi → PAS → Hapus Cache (bukan Hapus Data). Buka ulang.

4

Perbarui aplikasi

Unduh APK terbaru dari situs resmi bila versi Anda lama (cek di menu Tentang).

5

Hubungi manusia

Urutan: wali kelas → guru pembimbing → TU/IT sekolah → adminpusat@pusat.com. Sertakan screenshot + jam kejadian.
